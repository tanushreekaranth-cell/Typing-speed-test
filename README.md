🎯 Typing Speed Test

A simple web-based typing speed test made using HTML, CSS, and JavaScript.

Features

- ⏱️ 30-second timer
- ⚡ WPM calculation
- 🎯 Accuracy tracking
- 🟢 Correct letters in green
- 🔴 Wrong letters in red
- 🔄 Restart button

Technologies

- HTML
- CSS
- JavaScript

How to Run

1. Download the project.
2. Open "index.html" in a browser.
3. Click Start.
4. Start typing and check your WPM and accuracy.
